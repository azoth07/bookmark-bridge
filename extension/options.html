    书签桥设置
    01 / 连接

    连接本机书签桥

    仅限本机

    从服务窗口复制令牌，在 Chrome 和 Edge 中填写同一份。双方确认完成后，磁盘上的令牌会随整个数据目录一起删除；当前服务仍可继续同步。清理后重启服务会生成新令牌，需在两边重新填写。

    开启后约每分钟检查一次。手动同步尚未等到双方完成时，即使关闭此项，也会每分钟继续检查。

    02 / 配对

    选择要同步的文件夹

    已为你准备好配对 1。在 Chrome 和 Edge 的同一配对编号下，各自选择一个本地文件夹，再分别点击“立即同步”。

    Chrome · 本地文件夹配对 1Edge · 本地文件夹

    文件夹名称可以不同。两边需启用相同的配对编号；移除配对不会改变其他编号。添加时会使用最小的空闲编号，最多 50 对。

    还没有文件夹配对

    点击“添加配对”，在两边相同的编号下选择要共享的收藏。

    正在读取设置…立即同步会先保存当前设置。

    开始之前，了解同步方式

    • 只补齐，不删除。按文件夹递归合并，同一路径下相同网址不重复添加，现有重复项不清理，同名子文件夹继续合并。
    • 等双方全部应用，再清理。Chrome 和 Edge 必须启用相同的配对编号，并分别应用所有配对的最新合并结果。之后服务才会删除整个临时数据目录，包括磁盘上的令牌。仅本机应用完成时不会清理。
    • 当前服务继续保留内存中的合并内容。删除和重命名不会传播，原有内容可能在下次同步时补回；移动或重命名可能产生额外副本。新的内容会再次临时写入磁盘，等双方确认后再删除目录。清理后重启服务，旧的内存内容消失，需要用新令牌重新配对，再从浏览器书签开始合并。
    • 两边都要保持运行。请打开 Chrome 和 Edge，并保持本机书签桥服务运行。在两边各点一次“立即同步”，等待期间会每分钟继续检查。服务窗口也会实时显示进度。
